Link courses

Links every Champions Meeting and League of Heroes event to the course the game says it runs on. The links come from the JP game data in the site's code, so a new event appears here once that data is refreshed.

An event already linked to a different course keeps it unless you tick Replace. The preview also lists the typed course details (the text on each event's page) that disagree with the game. This page never changes that text: fix it on the event's page.
