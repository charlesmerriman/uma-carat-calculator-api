Import courses

Upload the course bundle: one JSON file holding every course's corners, straights, hills and shape, built from Daptrius's game files. It adds new courses and updates the ones already here.

It keeps your choices: a path you swapped, a map you hid and the lap layout stay as they are. It never deletes a course, and it doesn't link events. That's the Link courses page, next.
